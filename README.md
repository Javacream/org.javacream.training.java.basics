# Java – Grundlagen und Praxis

**Empfohlene Dauer:** 4 Tage

**Voraussetzungen:** Grundlegende Kenntnisse der Programmierung sind hilfreich, praktische Java-Erfahrung wird nicht vorausgesetzt.

### Abstract

Dieses Training vermittelt die grundlegenden Konzepte der Programmiersprache Java und deren praktische Anwendung in der Softwareentwicklung. Die Teilnehmenden lernen den Aufbau von Java-Anwendungen, die Verwendung von Variablen und Datentypen sowie die Steuerung des Programmablaufs mit Bedingungen und Schleifen kennen. Weitere Schwerpunkte sind Methoden, Klassen, Objekte und die wesentlichen Prinzipien der objektorientierten Programmierung. Ergänzend werden die Behandlung von Ausnahmen, grundlegende Klassenbibliotheken und der Umgang mit Collections vorgestellt. Anhand praxisnaher Beispiele und Übungen entwickeln die Teilnehmenden eigene Java-Programme und lernen, diese zu testen und zu debuggen. Ziel ist es, eine solide Grundlage für die eigenständige Entwicklung und Weiterentwicklung von Java-Anwendungen zu schaffen.

# Java – Fundamentals and Practice

**Recommended Duration:** 4 days

**Prerequisites:** Basic programming knowledge is helpful. Previous experience with Java is not required.

### Abstract

This training introduces the fundamental concepts of the Java programming language and their practical application in software development. Participants learn how Java applications are structured and how to work with variables, data types, conditional statements, and loops. Further topics include methods, classes, objects, and the essential principles of object-oriented programming. The training also covers exception handling, important parts of the Java standard library, and working with collections. Through practical examples and hands-on exercises, participants develop their own Java programs and learn how to test and debug them. The objective is to establish a solid foundation for independently developing and maintaining Java applications.
